# Data Engineering & Analytics Lab

A technical portfolio documenting my hands-on work in **Data Engineering, Data Warehousing, ETL, Cloud Data Processing, Data Analytics, Machine Learning, and Business Intelligence**.

This repository contains academic projects, technical practices, and data-focused experiments developed while studying Systems Engineering.

The projects focus on building data pipelines, integrating and transforming data, designing analytical data models, optimizing data processing, working with cloud data platforms, and turning data into actionable insights.



## Featured Projects

### [SG-Food Data Integration & Data Warehouse](./projects/sg-food-data-integration)

End-to-end data integration and Data Warehouse project involving multiple data sources, ETL processes, staging, dimensional modeling, and analytical processing.

**Main Technologies:**  
`SQL Server` · `SSIS` · `SSAS` · `T-SQL` · `ETL` · `Data Warehousing`



### [NYC Taxi Data Engineering & Analytics](./projects/nyc-taxi-bigquery-analytics)

Large-scale data processing and analytics project using more than **36 million NYC taxi trip records from 2022**.

The project includes data cleaning, feature engineering, BigQuery partitioning and clustering, query optimization, predictive modeling with BigQuery ML, and data visualization with Looker Studio.

**Main Technologies:**  
`Google BigQuery` · `SQL` · `BigQuery ML` · `Partitioning` · `Clustering` · `Looker Studio`
