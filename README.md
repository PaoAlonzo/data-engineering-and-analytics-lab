# Data Engineering & Analytics Lab

A collection of academic projects and technical practices focused on Data Engineering, Data Warehousing, ETL, Data Analytics, Cloud Data Processing and Business Intelligence.

This repository documents my hands-on learning journey in building data pipelines, designing analytical data models, processing datasets and transforming data into actionable insights.
